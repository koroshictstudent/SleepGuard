# SleepGuard 💻

**A free Windows application for building healthier sleep habits.**

SleepGuard helps users maintain a consistent sleep schedule by automatically shutting down their computer during configured restricted hours.

## Features
- Customizable nighttime restriction schedules
- Automatic shutdown during restricted hours
- Password-protected settings
- Configurable startup grace period

## Important Information
SleepGuard can automatically shut down your computer. Always save your work and carefully review your configured schedule.

The Windows executable is currently distributed without a trusted publisher code-signing certificate.
